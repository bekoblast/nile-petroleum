# Nile Petroleum (Nilepet)

Corporate website for **Nile Petroleum Company Limited (Nilepet)** — Sudan's national oil company, with integrated operations across exploration, production, refining, distribution, and a 450+ station retail network.

## Features

- Bilingual EN / AR interface (with RTL support for Arabic)
- Multi-page architecture covering About, Services, Products, Careers, Contact, and more
- Lightweight, fast, fully static

## Stack

Static HTML / CSS / JavaScript. No build step.

## Local dev

```bash
# from this folder
python -m http.server 8080
# then visit http://localhost:8080
```

## Deploy

Connected to Cloudflare Pages — every push to `main` auto-deploys in ~30 seconds.
